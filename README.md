# Подоконник 5.0.3 — исправления

Патч к [оригинальному «Подоконнику» Александра Красникова](https://github.com/aleksandrkrasnikov97-dot/podokonnik). Он меняет исходники версии 5.0.3. Для запуска потребуется собрать приложение.

## Что исправлено

- Скачанные или перекодированные обои включаются на выбранном мониторе.
- Текущие обои сохраняются, пока новые скачиваются или перекодируются, а также при ошибке подготовки. Настройки отдельных мониторов сбрасываются после успешного выбора обоев для всех экранов.
- Если выбранный монитор уже отключён, запрос игнорируется. Обои, назначенные только на отдельные мониторы, учитываются при перезапуске обоев и в меню трея.
- Скрипт сборки сам создаёт папку `build` и явно указывает Windows 10 как целевую версию SDK.

## Как применить

1. Распакуйте [исходники 5.0.3](https://github.com/aleksandrkrasnikov97-dot/podokonnik/blob/c7a494fcadd37a375d20c08065ea9ebeaa4d7133/podokonnik-source.zip).
2. Скачайте `podokonnik-5.0.3-fixes.patch` из раздела Releases и положите его рядом с `app.h` в распакованной папке.
3. В этой папке выполните команды:

```sh
git apply --check podokonnik-5.0.3-fixes.patch
git apply podokonnik-5.0.3-fixes.patch
```

SHA-256 исходного архива — `35f593c26b94e03fba07fadc7359ce4137871ede4c4e8634c6270b0eebf52a5e`.

## Проверка и сборка

`sh build.sh html` собирает HTML-ресурсы приложения. Основной C++ файл проверен компилятором LLVM-MinGW с целевой версией Windows 10. Скрипт `test-wallpapers.py` компилирует код выбора обоев с заглушками для скачивания и рабочего стола. Для запуска передайте путь к распакованным исходникам и путь к компилятору C++ (LLVM-MinGW).

```powershell
py -3 test-wallpapers.py C:\path\to\podokonnik-source C:\path\to\llvm-mingw\bin\x86_64-w64-mingw32-clang++.exe
```

Публичный архив исходников не содержит всех входных файлов полной сборки. В частности, в нём отсутствуют HTML-сборка Студии, загрузчик WebView2 и собранные DLL оформления. Проверки проводились без установки и запуска программы.
